Notre Vision

Un projet réel,
une communauté
passionnée

Faucon est né d'une conviction simple : apprendre la robotique est plus enrichissant sur un projet concret, avec de vraies contraintes d'ingénierie, plutôt que sur des exercices déconnectés.

La communauté MA64 Robotics réunit des passionnés autour d'un défi ambitieux : faire collaborer un robot mobile et un drone dans un contexte agricole réel, en s'appuyant sur les technologies les plus modernes de la robotique open source.

Que tu sois débutant ou expert, le projet Faucon est conçu pour que tu puisses contribuer, apprendre et progresser à ton rythme sur un cas d'usage industriel.

🎯

Au cœur du projet

La collaboration Robot × Drone

L'enjeu central de Faucon : orchestrer deux entités autonomes complémentaires pour maximiser la connaissance du terrain et l'efficacité des missions agricoles.

🤖

Robot Mobile (Faucon Ground)

Opère au niveau du sol dans les rangs du champ

  • Navigation autonome avec Nav2 dans l'environnement agricole
  • Détection des rangs de maïs par nuage de points LiDAR
  • Équipement de pulvérisation pour le traitement des plantes
  • Contrôle 4WS (4 roues directrices) pour la manœuvrabilité
  • Deux configurations : Full et Mini
  • Détection de déchets dans le champ

Ce que nous avons construit

Des briques pour chaque couche du système

Chaque fonctionnalité est un module indépendant sur lequel tu peux contribuer ou t'appuyer pour apprendre.

🗺

Génération de trajectoire

Interface graphique (GUI) pour définir et générer des trajectoires de navigation dans le champ. Export en YAML compatible Nav2.

faucon_path_planning
🧭

Navigation autonome

Stack Nav2 pour les environnements agricoles. Suivi de trajectoire GPS waypoints et gestionnaire de mission complet : chargement YAML, START / PAUSE / RESUME / STOP, progression en temps réel.

faucon_navigation
👁

Détection de rangs de maïs

Algorithme de segmentation des rangs depuis les nuages de points 3D du LiDAR. Filtrage au sol et extraction des lignes de culture.

faucon_perception
📍

Localisation & Fusion capteurs

Fusion GPS/IMU/odométrie avec double EKF (robot_localization). Conversion LLH↔ENU, intégration MapViz pour la visualisation sur carte.

faucon_localisation
🌐

Interface de contrôle (IHM)

Dashboard web React embarqué : GPS temps réel, feed caméra, IMU, télémétrie, contrôle manuel, stop d'urgence et widget Mission Control (chargement de trajectoire, suivi de progression, commandes de mission).

faucon_ihm
🌳

Orchestration BehaviorTree

Coordination des comportements robot + drone via BehaviorTree.CPP : gestion de mission, vérification système, dispatch drone à la demande.

Faucon_Orchestration
🎮

Contrôle 4WS

Contrôleur dédié pour la cinématique 4-roues directrices. Gestion des angles de braquage et des vitesses de chaque roue indépendamment.

faucon_control
🌽

Environnement de simulation

Champ de maïs procédural dans Gazebo Sim. Végétation 3D réaliste, terrain texturé, obstacles (déchets) et marqueurs QR.

virtual_maize_field
🤖

Description robot URDF

Modèle complet Xacro du robot (Full & Mini) avec capteurs simulés : caméra RGB-D, LiDAR, GPS, IMU, intégration ros2_control.

faucon_base_desc

Démarrage rapide

Lancé en 3 étapes

Prérequis : Ubuntu 24.04 · ROS2 Jazzy · Gazebo Harmonic

1

Cloner & installer les dépendances

# Cloner le dépôt
git clone git@github.com:themasterofarts/Faucon_ma64.git
cd Faucon_ma64

rosdep update
rosdep install \
  --from-paths . \
  --ignore-src -y
2

Builder le workspace

# Build avec colcon
colcon build \
  --symlink-install

source install/setup.bash
3

Simulation seule

# Robot complet
./faucon/launch_base.sh

# Ou version Mini
./faucon/launch_base.sh \
  use_mini=true
4

Simulation + Navigation autonome

# Base + Nav2 + mission_manager
./faucon/launch_full.sh

# Build, démarrage base,
# puis navigation auto.
# Ctrl+C arrête tout.
